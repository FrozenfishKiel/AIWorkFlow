# Web App

这里是当前项目的正式前端工作区。

它现在的定位不是“任务控制台”，而是一个中文的 `商品内容生成工作页`。

## 用户在这里做什么

用户进入页面后，只需要完成一条很直接的流程：

1. 填写商品基础信息
2. 补一句这次想生成什么内容
3. 点击生成
4. 等待系统返回三类初稿
5. 在主结果区查看弱输入提醒、三类初稿和风险提示
6. 按需打开“生成依据”查看：
   - 系统理解
   - 参考资料
   - 卖点提炼
   - 风险提示
7. 导出结果继续编辑

## 当前已接通

- 中文首页与商品内容工作区
- 本机模型配置入口
- 商品信息表单
- 当前结果自动轮询
- 失效历史任务自动恢复清理
- 三类结果展示：
  - 电商卖点文案
  - 商品详情页文案
  - 小红书 / 种草短文案
- 弱输入提醒展示
- 生成依据抽屉
- 当前结果导出
- 最小登录页：
  - 密码登录模式
  - legacy token 模式兼容

## 首次使用提醒

如果这台机器还没配置模型参数，进入工作台后会先出现“本机模型配置”卡片。

你可以直接在页面里填写：

- `DeepSeek API Key`
- `DeepSeek Base URL`
- `DeepSeek 模型`

保存后会写入后端本地文件 `apps/api/.env.local`。

## 当前前端边界

- 前端不再把任务列表、知识索引、导出历史作为首屏主视图
- 当前输出默认定位为 `高质量初稿`
- 前端只消费结构化接口，不在组件里拼后端协议
- 当前正式交互仍然使用轮询，不使用 WebSocket
