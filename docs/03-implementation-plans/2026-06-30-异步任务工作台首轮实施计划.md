# 异步任务工作台首轮实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or equivalent task-by-task execution discipline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落出第一版可运行的异步任务工作台闭环，包含任务创建、异步处理、状态轮询、审核前结果展示和基础验证脚本。

**Architecture:** 后端采用 `FastAPI + SQLModel + Celery + Redis` 建立异步主链路，前端采用 `React + Vite` 提供任务台和轮询详情页。本轮不追求模型真实接入，先用可替换的 stub 流程把结构、状态机、任务编排、审计和导出入口搭稳。

**Tech Stack:** `FastAPI`, `SQLModel`, `Celery`, `Redis`, `PostgreSQL/SQLite fallback`, `React`, `TypeScript`, `Vite`, `Vitest`, `pytest`
