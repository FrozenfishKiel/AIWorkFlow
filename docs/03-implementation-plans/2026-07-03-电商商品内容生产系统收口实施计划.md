# 电商商品内容生产系统收口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把当前仓库从旧的内容任务工作台收口为“电商商品内容生产系统”的第一版可运行主链。

**Architecture:** 后端继续复用现有 FastAPI、SQLModel、检索与生成底座，但把输入契约、结果契约和主链提示词切到电商商品内容生成语义。前端收口为一个中文商品内容生成页，系统内部直接沉淀最小电商业务资料包，不再依赖用户先手动登记知识资料。

**Tech Stack:** FastAPI, SQLModel, React, Vite, Vitest, pytest
