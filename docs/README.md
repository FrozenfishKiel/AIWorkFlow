# Docs Index

这个目录专门存放项目级文档，不只放需求文档。

建议检索顺序：

1. `01-project-specs`
   找项目目标、边界、命名、上线标准、阶段约束。
2. `02-architecture`
   找系统结构、模块职责、主链路、数据流。
3. `03-implementation-plans`
   找开发任务拆解、迭代顺序、里程碑。
4. `04-development-guides`
   找环境、运行、部署、工程协作规范。
5. `05-interview-notes`
   找项目讲解、八股映射、技术追问准备。

命名约定：

- 需求类文档：`YYYY-MM-DD-主题.md`
- 计划类文档：`YYYY-MM-DD-主题-计划.md`
- 架构类文档：`YYYY-MM-DD-主题-架构.md`
- 指南类文档：`YYYY-MM-DD-主题-说明.md`
- 面试类文档：`YYYY-MM-DD-主题-面试.md`

这样做的目的，是让人和 AI 都能按日期、主题、文档类型三条线检索。
