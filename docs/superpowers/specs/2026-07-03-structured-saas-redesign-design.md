# 电商商品内容生产系统前端重做设计方案

## 目标

为当前项目重做一版前端视觉与信息结构，采用更克制的中文软件产品表达，交付两层结构：

- 官网首屏
- 工作台主页面

这版设计不展示系统内部流程，而是让用户直接感受到这是一套已经成型的商品内容生产产品。

## 硬约束

- 不展示任务列表
- 不展示异步阶段状态
- 不展示技术流程、系统处理说明、调试视图
- 不展示用户看不懂也不想看的工程细节
- 不做“半成品后台”或“流程控制台”气质
- 不主动扩展移动端方案
- 全中文文案，不夹英文标签
- 不设置围绕可信度包装或补充说明堆叠的首页模块

## 产品定位

产品正式名称保持为 `电商商品内容生产系统`。

首屏主诉求保持为：
`让运营更快拿到可编辑的高质量初稿`

价值表达聚焦于：

- 统一商品口径
- 一次产出三类内容
- 页面只保留输入与结果

## 页面结构

### 一、官网首屏

官网首屏负责讲清楚产品价值，不负责讲技术路径。

首屏核心模块：

1. 顶部导航
2. 主标题与一句价值说明
3. 明确的主行动按钮
4. 结果预览型主视觉
5. 三个价值说明面板

主视觉必须展示成品感结果，而不是流程图或后台截图。它应该暗示：

- 商品理解摘要
- 卖点文案
- 详情页片段
- 辅助提示

首页不再单独设置说明型补充区块。风险提醒和参考依据可以出现在结果预览或工作台结果区中，但只能作为轻量辅助信息存在。

### 二、工作台主页面

工作台主页面负责让用户直接开始输入，并快速看到结果。

结构固定为：

- 左侧输入面板
- 右侧结果面板

左侧输入面板不是后台表单墙，而是语义分组清晰的产品录入区。

建议分组：

- 商品基础信息
- 商品卖点信息
- 本次任务说明

右侧结果面板是用户继续编辑内容的主工作面，不是系统中间态展示。

结果顺序固定为：

1. 商品理解摘要
2. 电商卖点文案
3. 商品详情页文案
4. 小红书 / 种草短文案
5. 风险提醒
6. 参考依据

其中前四项是主要结果，后两项是低权重辅助信息。导出动作只作为结果页自然动作存在，不单独做导出中心。

## 视觉系统

### 颜色

- 主背景：冷白
- 主文字：深墨
- 强调色：深绿
- 辅助色：冷灰

不引入促销色、电商活动色或过强的营销配色。

### 排版

- 强调留白和秩序
- 通过对齐、间距、字号层级建立信息结构
- 避免大面积色块切割页面
- 避免解释型信息堆叠成说明墙

### 图形语言

保留少量现代艺术感，但只能作为秩序背景，不做视觉主角。

可使用：

- 极淡几何块面
- 低饱和背景渐变
- 轻量线性分隔

不使用：

- 插画主视觉
- 科技光效
- 促销海报感

## 组件约束

### 按钮

- 主按钮明确、有分量，但不过度发光
- 次按钮轻量、克制
- 全中文文案

### 输入组件

- 表单感弱化
- 留白充足
- 边框轻
- 聚焦态清晰但不过分抢眼

### 结果模块

- 主要结果偏内容阅读与编辑感
- 风险提醒和参考依据偏辅助说明型
- 不让所有模块视觉上完全同质

### 错误与空态

- 文案克制
- 不使用工程化术语
- 不做后台报警气质

## 原型范围

原型采用“半交互”深度：

- 可在官网首屏与工作台主页面之间切换
- 可填写或查看商品输入信息
- 可触发生成功作并看到加载态
- 可查看生成完成后的结果展示
- 可保留结果导出动作入口

原型不实现真实后端接入，不展示完整系统流程。

## 预期效果

用户打开官网首屏时，应感受到：

- 这是一个成熟产品
- 它很克制，不炫技
- 它明确知道用户只关心输入和结果

用户进入工作台后，应感受到：

- 界面顺手
- 信息清晰
- 结果有成品感
- 辅助信息存在，但不喧宾夺主

## 不采纳方向

以下方向在本次设计中明确排除：

- 任务工作台心智
- 流程跑图式前端
- 调试面板式结果展示
- 任务列表主视图
- 导出历史主视图
- 审计日志主视图
- 首页说明卡堆叠
