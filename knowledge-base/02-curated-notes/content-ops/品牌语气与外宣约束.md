# 品牌语气与外宣约束

适用范围：

- 新品发布文案
- 活动预热内容
- 对外说明型图文

核心要求：

- 语气要稳定、克制、可复核，不要写成情绪化口号。
- 能说清楚的能力点才允许对外写，不能把内部设想写成已上线事实。
- 如果一句话涉及效果、收益、提升、承诺，默认需要补证据来源或改成更保守表述。
- 对外内容优先使用“可验证事实 + 业务价值 + 使用场景”的结构，不要一上来堆结论。

推荐表达：

- “当前版本已支持……”
- “适用于……场景”
- “可以帮助团队更快完成……”
- “建议结合……资料一起理解”

避免表达：

- “行业最强”
- “全面替代人工”
- “零成本上线”
- “一定提升转化”

发布前检查：

- 是否有一句话把试验性能力写成稳定能力。
- 是否有外部读者无法验证的绝对化表述。
- 是否明确区分“已经实现”和“计划支持”。
