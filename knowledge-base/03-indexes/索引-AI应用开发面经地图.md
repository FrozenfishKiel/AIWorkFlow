# 索引：AI 应用开发面经地图

## 目的

这份地图不是为了堆“面试题目录”，而是为了回答当前项目最现实的三个问题：

1. AI 应用开发面试里最容易被追问什么。
2. 这些追问和我们当前项目主链分别对应哪一段。
3. 哪些东西该继续打磨，哪些东西该重点展示。

对当前项目来说，这张地图的价值不在“背题”，而在“把项目讲法和面试官关注点对齐”。

## 当前项目最该优先看的 5 个主题

### 1. AI 开发八股

- `game_ai_dev\output\research-notes\ai-interview-research\01-主题\AI开发八股.md`

看它不是为了死背术语，而是为了确认当前 AI 开发岗的高频问题大致收敛在哪几块：

- Agent
- RAG
- 工具调用
- LLM 基础
- 工程化
- 评测与安全

对当前项目最有价值的是后四块，因为它们直接对应主链质量，而不是名词包装。

### 2. RAG

- `game_ai_dev\output\research-notes\ai-interview-research\01-主题\RAG.md`

这页最贴当前项目，因为它直接指向：

- chunk 怎么切
- 检索、召回、重排怎么做
- Query Rewrite 怎么做
- 混合检索为什么更常见
- RAG 幻觉怎么处理
- RAG 效果怎么评估

如果项目里命中依据、上下文组装和评测说不清，这一块最容易被问穿。

### 3. 项目类型与技术栈

- `game_ai_dev\output\research-notes\ai-interview-research\01-主题\项目类型与技术栈.md`

这页帮助我们判断：当前项目该把自己讲成什么，不该讲成什么。

它的价值不在于“照抄技术栈”，而在于提醒我们：

- 面试官更关心系统设计和取舍
- AI 开发岗高频项目多半是系统项目，不是模型训练项目
- 项目一定要能沿着链路一路讲下去

### 4. 大厂候选人项目画像

- `game_ai_dev\output\research-notes\ai-interview-research\01-主题\大厂候选人项目画像.md`

这页的价值很直接：它告诉我们，通过大厂面试的人，手里的项目通常长什么样。

对当前项目最重要的提醒是：

- 轻 SaaS 壳子不够
- 面试官更想听链路、检索、工具、失败分支、评测、监控和稳定性
- 项目要像一个系统，而不是一个会吐字的页面

### 5. 跟着面经做的最稳项目

- `game_ai_dev\output\research-notes\ai-interview-research\01-主题\跟着面经做的最稳项目.md`

这页非常适合拿来做边界判断。
它的结论是：最稳的项目通常是 `生产级 RAG + 工作流 / 单 Agent 的企业流程知识助手`。

对我们项目的启发不是去抄一个企业流程助手，而是确认当前路线没有跑偏：

- 不要把重点放在轻聊天壳子
- 不要先堆多 Agent 名词
- 要把 RAG、工作流、风险控制和评测讲实

## 和当前项目主链的对应关系

当前项目正式主链是：

`商品理解 -> 资料命中 -> 卖点提炼 -> 多类型文案生成 -> 风险提醒 -> 导出交付`

把它挂回面经地图后，对应关系可以收成下面这张表：

- `商品理解`
  对应结构化输入理解、任务拆解、上下文压缩和约束注入。
- `资料命中`
  对应 RAG、检索、召回、重排、证据引用和命中失败处理。
- `卖点提炼`
  对应中间表示设计、共享语义层和生成前约束整理。
- `多类型文案生成`
  对应工作流编排、模板约束、结果一致性和多结果组织。
- `风险提醒`
  对应评测与安全、幻觉约束、人工复核点和结果护栏。
- `导出交付`
  对应结果结构化、可回溯性、可用性和业务闭环。

## 当前项目最值得打磨的 4 块

### RAG 命中质量

把“为什么命中这几条”和“这些资料怎样真正参与生成”讲清楚。

### 主链编排

把每一段为什么存在、输入输出是什么、失败时怎么退，讲清楚。

### 生成约束与风险控制

把结果为什么没有乱写、为什么能提醒风险，做成真机制，不做假模块。

### 评测与回归

补稳定样本，让主链优化能被证明，而不是只靠主观感觉。

## 当前项目最适合展示的内容

前端和演示里，最适合露给用户和面试官看的，不是平台壳，而是：

- 输入是什么
- 系统理解了什么
- 命中了什么资料
- 卖点如何被提炼
- 最终生成了哪三类文案
- 有哪些风险提醒

不适合继续堆前端的，是那些用户看不懂、也不想看的流程噪音：

- 假平台感的空功能
- 过重的任务列表
- 没实际意义的可信度装饰
- 与当前主链无关的演示模块
