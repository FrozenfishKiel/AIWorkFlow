# Knowledge Base Index

这个目录专门存放与项目开发、学习、面试准备相关的知识资料，不是代码目录。

目录说明：

- `01-sources`
  原始资料入口，适合存放链接、摘录、原始整理结果、来源记录。
- `02-curated-notes`
  二次整理后的主题笔记、结论总结、项目参考资料。
- `03-indexes`
  面向检索的索引文档、主题词导航、标签入口。

当前还支持一种轻量外部知识接入方式：

- 在 `01-sources/external/<domain>` 中保存“外部知识入口卡片”
- 在 `03-indexes` 中保存“本项目如何查这些外部知识”的导航索引

这样可以把外部大型知识库接进当前项目，而不用一次性复制大量原文。

建议原则：

- 原始资料尽量先放 `01-sources`
- 经过提炼和重写的内容放 `02-curated-notes`
- 所有方便检索的导航文档放 `03-indexes`

当前仓库已经补了一组可直接演示的占位业务域资料：

- `02-curated-notes/content-ops/品牌语气与外宣约束.md`
- `02-curated-notes/content-ops/发布前审批与证据规范.md`
- `02-curated-notes/content-ops/内容任务拆解模板.md`

它们的定位不是正式业务知识库，而是第一轮联调用的 `content-ops` 占位知识域。

命名约定：

- 来源类：`来源-平台-主题.md`
- 整理类：`主题-结论.md`
- 索引类：`索引-用途.md`、`索引-主题词.md`

这样后续不管你用“面经”“RAG”“上线”“部署”“项目深挖”这种词来找，AI 都更容易命中。
