# 新品发布任务简报

我们准备发布一篇介绍“AI内容生产与运营工作流系统”当前进展的图文。

目标：

- 面向内容运营与产品协作团队，说明这套系统当前已经能做什么。
- 输出语气要克制，不要把未完成能力写成已上线能力。

已知事实：

- 系统支持文本、URL、文件三种输入方式。
- 已经有异步任务主链、结构化理解结果、知识检索、工作流结果、导出能力。
- 目前新增了真实模型理解与生成链，以及基于 retrieval profile 和 embedding vector 的混合检索。

约束：

- 凡是涉及“效果提升”“完全自动化”“无需人工”之类表述都要谨慎。
- 需要保留可追溯来源和待确认项。
- 对外内容发布前仍要看审批与证据要求。
